# Resilient Futures Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single `index.html` landing page for Resilient Futures using the approved design spec at `docs/superpowers/specs/2026-04-15-homepage-design.md`.

**Architecture:** Single `index.html` at the project root. All styles live in a `<style>` block (custom CSS) plus Tailwind CDN for utilities. Sections are built one at a time, screenshot-verified after each against the spec, then assembled into the final file. The dev server (`node serve.mjs`) serves at `http://localhost:3000`.

**Tech Stack:** HTML5, custom CSS + Tailwind CSS CDN, Google Fonts (Playfair Display + Inter), Puppeteer (screenshots via `node screenshot.mjs`), Node.js dev server (`node serve.mjs`).

## Colour & Type Reference (memorise before starting)

**Colours**
- Primary: `#361F1D` (dark bg, headings on light)
- Accent: `#743734` (H3, hover states)
- Highlight: `#FF6139` (CTAs, bullets, `+` mark)
- Secondary: `#A1CACC` (trust labels, section labels on dark)
- Background: `#F5F5ED` (alternating section bg)
- White: `#FFFFFF`
- Body Text: `#1A1A1A`
- Mid Grey: `#6B5350`
- Light Grey: `#D8D0C8`

**Typography**
- Headings (H1–H3, pullquotes): Playfair Display Bold 700 / italic 400
- Everything else: Inter 300 / 400 / 500 / 600
- Section labels: Inter Semi-Bold 600, 9–10px, ALL CAPS, `#FF6139`, +0.18em tracking
- Body: Inter Regular 400, 14–15px, `#1A1A1A`, 1.7 line-height
- **No em dashes anywhere.** No `transition-all`. Animate only `transform` and `opacity`.
